Code-Splitting & Lazy Loading QRScannerModal

Code Splitting / Perf

Previous Inefficiency

QRScannerModal was statically imported at the root of the (dashboard) layout. Because the dashboard layout wraps every admin route (clients, treatments, memberships, analytics, settings), the entire QR modal tree—including Realtime Database listeners, Firestore mutation logic, and camera-binding code—was bundled into every page's initial chunk, even when the modal was never invoked.

Optimized Solution

Converted to next/dynamic(() => import("@/components/QRScannerModal"), { ssr: false }). This separates the QR scanner into an on-demand async chunk that is fetched only when the modal opens. The ssr: false flag prevents camera device API hydration issues during server rendering.

Polymorphic Skeletons, Responsive Overflow & WCAG A11y

CLS & A11y

Previous Inefficiency

One rigid CardGridSkeleton with fixed h-32 images was used across all pages regardless of aspect ratio. When real 16:9 banners, 2-column memberships, or reward cards rendered, the page snapped dramatically causing Cumulative Layout Shift (CLS). Furthermore, skeletons lacked ARIA attributes and used jarring infinite pulse animations without prefers-reduced-motion compliance.

Optimized Solution

Added polymorphic variant dispatching ("treatment" | "membership" | "reward" | "banner" | "blog") with exact bounding boxes, added dedicated ListSkeleton, upgraded TableSkeleton with horizontal overflow resilience (minWidth: cols * 112), and integrated full WCAG 2.2 accessibility (role="status", aria-label, aria-hidden, sr-only, and motion-safe:animate-pulse).

Previous Inefficiency

Workspaces used "lint": "next lint", which boots the full Next.js CLI runtime, prints telemetry overhead, and often has issues in nested monorepo configurations. There was also no standalone typechecking script, requiring developers to run a full next build just to catch TypeScript errors.

Replaced with direct "lint": "eslint ." for fast zero-overhead workspace linting, and added "typecheck": "tsc --noEmit". Typechecking can now execute across packages in milliseconds without emitting build artifacts or executing webpack/turbopack compilation.
